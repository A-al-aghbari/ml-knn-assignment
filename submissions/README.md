# Submissions

Each student creates **one folder** here, named:

```
<studentnumber>_<FirstName>
```

Example: `20231234_Ahmed` (English letters only, no spaces).

The folder must contain:

| File | What |
| --- | --- |
| `knn_assignment.ipynb` | Your completed notebook, run from top to bottom |
| `answers.md` | Your answers (copy from `_template/answers.md`) |

Do not edit `_template/` or anyone else's folder. See the main [README](../README.md) for how to submit.
